 Key core options in gem5:
CPU type:
Selecting the specific CPU model to use, such as "O3", "Atomic", "Timing", or "KVM", each with different architectural characteristics. 
Cache sizes:
Specifying the sizes of the L1, L2, and L3 caches (data and instruction) for the CPU. 
Cache associativity:
Setting the level of associativity for the caches (e.g., direct-mapped, 2-way, 8-way). 
Pipeline stages:
Configuring the number of pipeline stages in the CPU design, impacting instruction fetch and execution parallelism. 
Instruction set architecture (ISA):
Choosing the instruction set the CPU will emulate, like x86, ARM, or RISC-V. 
Branch prediction:
Adjusting the branch prediction mechanism used by the CPU, impacting performance for branching instructions. 
Clock speed:
Setting the clock frequency of the CPU core.
